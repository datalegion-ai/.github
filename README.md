# .github

The public profile of the [Data Legion](https://www.datalegion.ai) GitHub organization.

`profile/README.md` is what [github.com/datalegion-ai](https://github.com/datalegion-ai) shows above the repositories: what Data Legion is, the ways to use it (API, MCP server, SDKs, CLI, bulk datasets), the integrations, and a first request. Edit that file to change the page; GitHub publishes it as soon as the change reaches `main`.

Keep it in step with the product: every link points at a live page on [datalegion.ai](https://www.datalegion.ai), and a new SDK, integration or delivery format gets its row in the same week it launches.
